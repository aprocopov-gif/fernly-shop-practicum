# Test plan: feature/fernly-helper

## Summary

Every page mounts **Ask Fernly** (`HelperWidget` in `Layout`): the customer chats; `POST /api/helper/chat` returns a reply and optional tool call (`search_plants`, `open_plant`, `add_to_cart`, `care_tip`); the browser runs the tool. The API stand-in can miss sometimes; `HELPER_SEED` makes choices repeatable; in development `window.__fernlyHelper` records and can run tools directly. Expectations below are the documented ones in `docs/features/fernly-helper.md`, `docs/PRODUCT.md`, and the OpenAPI text this change registers: a failure against the app is a possible finding, not a reason to change the assertion. CSS for the widget and `docs/features/fernly-helper.md` are covered by these rows. Nothing in `package.json` or config changed, so this plan does not schedule a full-suite run. This plan is not approved. Rows Q1–Q4 stay unresolved (`assumed — ask`) and get no test until a human resolves them.
